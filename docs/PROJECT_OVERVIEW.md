# Project Overview
CreditIQ turns the Home Credit relational tables into an applicant-level PD model and a decision-support application. Primary output is a calibrated PD, a configurable risk band, SHAP-based risk factors, a recommendation level (Further assessment / Manual review / Enhanced review / Escalated review) and illustrative ECL under three LGD scenarios. It does **not** approve or reject loans.

Deliverables map: data audit & dictionary, leakage audit, EDA report, statistical tests, feature docs, model comparison, calibration, SHAP, risk engine, ECL, portfolio analytics, fairness report, drift monitoring, API, dashboard (9 pages), tests, export bundle, model card.
